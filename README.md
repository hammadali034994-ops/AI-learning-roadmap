# AI Learning Roadmap Generator

A Streamlit web application that uses Google's Gemini Flash model to generate personalized learning roadmaps. Users input their skill level, available time, and desired domain, and the app outputs a structured plan.

## Features
- **Personalized Paths**: Tailored to Beginner, Intermediate, or Advanced levels.
- **Time-Aware**: Suggests timelines based on your available hours.
- **Powered by Gemini**: Uses the `gemini-2.5-flash` model for fast, high-quality generation.
